# Supplier Performance Intelligence Platform

## Mock UX Design

Figma Link:
https://www.figma.com/design/dENGRYCrc4cn6Mmcymav7R/Untitled?node-id=0-1&t=XfCHNGTr5VlG4Lzq-1

This Mock UX demonstrates the application's primary screens,
navigation flow, and major user journeys for the Supplier Performance
Intelligence Platform. It shows how procurement users can review
supplier performance, compare suppliers, and analyze cost, quality,
reliability, and delivery indicators.

### Main Screens

- Dashboard
- Supplier List
- Supplier Details
- Supplier Comparison
- Performance Analytics
- Reports

### Main User Journey

Dashboard → Supplier List → Select Supplier → Supplier Details
→ Performance Analytics → Supplier Comparison → Decision/Report
